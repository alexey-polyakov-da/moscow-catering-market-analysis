# Data

Проект использует два датасета на основе данных Яндекс Карт и Яндекс Бизнес за лето 2022 года:

- `rest_info.csv` — характеристики заведений, адреса, категории, режим работы, рейтинги, сетевой статус и количество мест;
- `rest_price.csv` — ценовая категория, описание среднего счёта, оценка среднего чека и стоимости чашки капучино.

Исходные CSV не включены в репозиторий. Ноутбук сначала ищет их в папке `data`, а при отсутствии загружает из открытого источника Яндекс Практикума.

Данные объединяются по уникальному полю `id`.
